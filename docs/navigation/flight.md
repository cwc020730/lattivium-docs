# 鞘翅飞行

飞行负责完成一个明确的飞行操作。长途旅行选择何时飞、从哪起飞和后续去哪里；飞行组件负责实际起飞、控制和到达核验。

## 飞行术语

| 术语 | 具体含义 |
| --- | --- |
| `FlightPolicy` | 到达距离、落稳等待、巡航高度和长短飞行参数 |
| 飞行路线 | 起飞位置、飞行几何与可选检查点 |
| 起飞位 | 满足起飞姿态和净空条件的位置 |
| 着陆候选 | 满足碰撞及落地条件的目标附近位置 |
| 落稳 | 飞行结束后，实际位置及移动状态满足结束条件 |
| 直接可用烟花 | 当前可立即使用的烟花库存，区别于仍装在盒内的数量 |

## ApproachAreaFlow

**输入：**当前维度的区域目标和交通策略。

它根据区域目标、实际位置、设备与资源选择区域接近方式，可能分成多个飞行航段或局部移动阶段。支持的接近目标采用 32 格水平与高度范围，具体定义见[到达条件](./targets#区域与候选目标)。

**输出：**所执行导航的实际结果。目标精确站位或容器交互由后续组件核验。

## ElytraFlightFlow

**输入：**飞行策略、目标、可选规划路线与出发位置。

```text
准备与起飞位置核对
  → ElytraTakeoffFlow
  → 爬升、巡航、下降
  → 选择着陆与控制接近
  → 落稳核验
```

短途跳飞与长途飞行使用相应策略。阻挡、起飞失败、资源不足或着陆条件变化时，流程在预算内尝试恢复或返回具体失败。

**输出：**`NavigationResult`，记录实际到达脚位及导航统计。上层旅行继续检查自己的最终到达条件。

## 燃料与补给

飞行需要可用鞘翅和普通推进烟花。飞行前的资源维护可以拆取携带盒内燃料或访问来源；拆盒需要落地并找到可操作的位置。

区域接近会考虑直接烟花与安全返回预留。单段公式、路线切段、补给门槛、盒内燃料和当前实现边界见[烟花估算与补给](./fuel)。旅行使用调用者提供的策略，实物获取复用材料能力；维护归属见[补给与执行恢复](../supply/maintenance#taskfireworksupply)。

## 查看飞行状态

Trace 中的准备、爬升、巡航、下降、着陆和恢复阶段用于观察。最终是否到达需结合实际维度、脚位、飞行状态和到达回执判断。

## 水面起飞

共同局部导航可在具备鞘翅和可用烟花时，从准入的水面节点起飞，到达有支持的目标。水下节点先通过共同游泳边到达水面；起飞净空、实体碰撞和资源仍由导航系统判断。施工或回收调用方只声明目标。原版在移动前采样水接触标志，通用飞行校验会同时核对当前位置的身体水接触，真实重新入水仍会拒绝。

水面起飞的水柱保持由共享 `TakeoffControl` 负责。原生跳跃与滑翔准备期间，它持续校正水平方向，保持在已准入且连续的开放水柱内；准备期间不会只在开始时对齐一次。离水后沿既有起飞控制交接，碰撞、净空、燃料、取消和输入释放仍使用同一合同。施工、挖掘与回收调用方不各自实现水柱转向。

规划和执行共用起飞事实：逻辑脚位、实际站姿、离水后的空中起点。短跳与直接飞行复用水面居中和原版跳跃/进入滑翔输入；燃料整理若离开起飞点，返回原逻辑脚位。半砖和箱顶保留当前支持格，不生成上方别名。水面、净空变化或取消时重新核验并释放输入。

24项水导航/起飞与16项相邻干地落点控制通过。这证明该共同能力，不代表湿地整场施工已经通过；旧起飞测试组仍有已记录的既有失败。
