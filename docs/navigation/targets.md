# 目的地与到达条件

旅行由目的地和到达条件定义。目的地给出需要前往的维度与参考位置；到达条件说明 Bot 在什么状态下算完成移动。

## 位置术语

| 术语 | 具体含义 |
| --- | --- |
| 维度 | 主世界、下界、末地等服务端世界标识 |
| Bot 脚位 | 人物碰撞体底部的实际位置 |
| 方块坐标 | 世界中某一方块格的整数坐标 |
| 目标脚位 | 要让 Bot 的脚到达的位置 |
| 参考位置 | 引导区域选择或搜索的坐标 |
| 候选站位 | 通过业务几何检查、可以尝试到达的格子 |
| `PathGoal` | 判断当前位置是否满足导航完成条件的接口 |

容器坐标指向库存方块；它的交互站位由访问流程决定。施工也可以给出多个允许站位。业务负责定义所需条件，导航负责尝试到达。

## TravelToFlow

**输入：**`GlobalPos` 目的地、可选 `PathGoal`、路线提示、搜索策略和本次已拒绝的航段。

```text
查询可用路线
  → 完成所选传送航段
  → ApproachAreaFlow：接近目标区域
  → LocalNavigationFlow：满足最终目标
  → 核对目标维度与到达条件
```

附近目标可以先尝试局部移动；同维度远途也可考虑经过其他维度绕行。阶段由实际位置、路线和策略选择，某些阶段可以直接跳过。

**输出：**`TravelArrival`，记录观察到的维度与实际脚位。仅有区域接近或穿门回执时，最终目标仍由该 Flow 核验。

## 命令目标

`TravelToFlow` 的注册命令接受目标维度和脚位。要求实际脚位到达目标方块底面中心 0.75 格范围内。完整命令及参数见[旅行总览](../guide/navigation#前往目的地)和[Flow 参考](../reference/flows#traveltoflow)。

台阶等部分高度支撑按同一 X/Z 的实际承重面核验。水面目标采用导航解析出的同列水面节点，水平距离仍需在 0.75 格内，脚位高度使用水面移动的浮动范围（节点 Y−0.75 至 Y+1.25）。解析与导航共享最低高度和现场碰撞约束。

## 区域与候选目标

内部调用可提供自定义完成条件。`ApproachAreaFlow.AreaGoal` 采用目标水平距离不超过 32 格、脚位高度差不超过 32 格且目标区块已加载的接近条件。

`NavigationRequest` 可包含具体候选站位，或包含探索式 `PathGoal`。探索请求的参考位置用于限定搜索方向与区域，实际完成由谓词决定。请求和结果的数据含义见[局部寻路](./local)。

## 返回位置

返回位置使用与旅行目的地相同的“维度 + 脚位”语义。获取材料、临时补给等业务保存自己的原目标或返回点，在子操作结束后从 Bot 的实际位置重新调用旅行。

交付位置表达要收到物品的容器；物品转移由[交付流程](../supply/delivery)负责。
