# 烟花储备与补给

旅行使用[库存要求与水位](../supply/stock)维护推进烟花。默认低于 **1,728 发**触发补给，目标为 **3,456 发**。这两个水位分别可配置。路线预测保留供 `AUTO` 模式使用。

## 库存与职责

| 名称 | 含义 |
| --- | --- |
| 推进烟花 | 烟花组件缺省或爆炸列表为空的烟花火箭 |
| 散装数量 | 主背包 36 格及副手的推进烟花，副手计一次 |
| 盒内数量 | 主背包携带潜影盒中的推进烟花，统计一层内容 |
| 实物数量 | 散装数量加盒内数量 |
| 可消费数量 | 实物中未被材料账本预留的数量；保留交付货物及其他用途的占用 |
| 下限 `minimum` | 低于该值时进入补给状态；等于下限时可继续 |
| 目标 `target` | 一次补给希望达到的可消费总量 |

`TaskFireworkSupply` 选择水位和补给操作；`StockRequirement` 表达数量要求；`SupplyRouteEstimator` 预测行程；`FireworkReserveFlow` 在起飞前拆出散装燃料；`FireworkUseFlow` 消费并结算实际烟花。

## 两种水位模式

### FIXED

```text
minimum = fireworkSupplyThreshold = 1728
target = fireworkSupplyTarget = 3456
```

`FIXED` 使用固定水位。低于下限时，开始补向目标。同一个来源的分批取货会继续进行，避免刚达到下限便结束、消耗一发后又重新补给。达到目标即可结清操作；当前来源已取完时，若数量达到下限且库存、借盒责任已经结清，也可恢复原操作。

### AUTO

```text
prediction = 所选行程的预测消耗
minimum = max(1, ceil(prediction × fireworkPredictionMultiplier))
target = ceil(minimum × fireworkSupplyTargetMultiplier)
```

两个系数默认分别为 `1.5` 和 `2.0`。例如行程预测为 200 发时，下限为 300 发，目标为 600 发。每次安全旅行边界可重新预测；一次补给片段的下限与目标在开始时固定，减少追逐移动目标的情况。

| 配置 | 默认值 | 范围 |
| --- | --- | --- |
| `fireworkSupplyMode` | `FIXED` | `FIXED`、`AUTO` |
| `fireworkSupplyThreshold` | `1728` | 1–10000 |
| `fireworkSupplyTarget` | `3456` | 下限–20000 |
| `fireworkPredictionMultiplier` | `1.5` | 1–10 |
| `fireworkSupplyTargetMultiplier` | `2.0` | 1–10 |

目标表示停止补取的水位。Bot 可以携带更多已持有燃料；原生合成按整批产出，实际结果可能略高于目标。

## 补给位置与恢复

低水位检查发生在父操作支持的安全边界。空中检查会等待安全落地，再推进补给。正在进行的容器、合成和借盒操作先结算。起飞准备中的拆盒和返回起飞点可经过浅水；实际起跳前会重新核验干燥位置。

1. 使用可消费的携带燃料，按需要拆盒。
2. 通过通用 `ReplenishSuppliesFlow` 查询并访问当前可达的普通推进烟花来源。
3. 常规来源尝试后，以上次实际成功取到燃料的来源作为回退；再次核验路线、容器和实物。
4. 现成烟花不足时，可由 `ProducePropulsionFuelFlow` 获取原料并完成原生合成。
5. 安全位置仍不足时进入 `WAITING_FOR_RESOURCE`，保留原目标、缺量、位置和原因。新增实物达到下限后重新校验并继续。

补给途中的烟花消耗计入实际库存。合成在取得原料后重新计算缺口，并完成已启动的原生合成批次。父操作在子操作结算后，从 Bot 实际位置恢复。

## 单段飞行怎么算

距离 d 为水平 X/Z 距离，负值按 0 处理。`ceil` 表示向上取整。

```text
长途航段 L(d) = 1 + ceil((60 + 0.020 × d) × 1.20)
短途跳飞 H(d) = 1 + max(3, ceil((2 + 0.045 × d) × 1.35))
```

长途公式中的 60 是起飞、爬升与着陆修正的固定经验消耗，0.020 是每格巡航估算，1.20 是数量裕量；最后的 1 是启动动力飞行的烟花。短途公式用于局部越障跳飞。

| 水平距离 | 长途公式 L(d) | 短途公式 H(d) |
| --- | --- | --- |
| 20 格 | 74 发 | 5 发 |
| 64 格 | 75 发 | 8 发 |
| 100 格 | 76 发 | 10 发 |
| 200 格 | 78 发 | 16 发 |
| 500 格 | 85 发 | 35 发 |
| 1,000 格 | 97 发 | 65 发 |

两列展示公式差异，实际使用哪列由飞行策略决定。长途公式的固定部分占比较高；这些数值是预测门槛，实际消耗需要核对烟花使用记录和实物变化。

## 怎么根据路线预测

`SupplyRouteEstimator` 根据 Bot 实际位置、目标和已记录传送路线估价，估价过程使用坐标事实。地形净空、真实出口和路径可执行性由旅行执行阶段核验。

```text
Bot 实际位置 → 第一扇门的入口
  传送 → 记录的出口 → 下一扇门的入口
  传送 → 记录的出口 → 最终目的地
```

每一段入口接近或最终接近分别估算，然后累加成 E。传送本身不消耗推进烟花。同维度目标也可以通过传送网络绕行，按所选路线的接近航段计数。

- 水平距离小于 64 格、目标上升不超过 32 格的接近段，在旅行估价中记为 0 发。
- 目标比当前位置高超过 32 格时，即使水平距离很短，也按长途公式计入。
- 每个接近段按最多 4,096 格切段。每段分别计算 L(d)，因此每次起飞都会计入固定消耗。
- `PortalJourneyFlow` 对已经选定的剩余传送路线单独估价，保留它的路线约束。

例如 5,000 格的单次接近会拆成 4,096 格和 904 格：

```text
E = L(4096) + L(904) = 172 + 95 = 267 发
```

如果直接把 5,000 代入长途公式，得到 193 发；当前旅行估价使用切段后的 267 发。切段与多次起飞是长距离数量增长的重要原因。

补给来源接近比较已选单向路线与随身可用烟花。同维度时，若已选路线燃料不足、直接接近可被现有燃料覆盖，则采用直接接近。飞行航段在安全落地后从随身运输盒准备直接可用烟花；后续返程由任务另行声明。


## 盒内烟花与起飞检查

旅行水位统计携带盒中的燃料。每段实际起飞还需要散装烟花：

```text
当前航段的最低散装量：L(d) 或 H(d)
散装补足目标：min(随身可用量, max(当前航段最低量, directFireworkTarget))
```

L0 已有足够的可消费烟花时，`FireworkReserveFlow` 直接允许本段飞行。数量不足时，调用 `EnsureInventoryReadyFlow` 把自有运输盒中的燃料准备到 L0 烟花槽。此时直接可用目标默认 192 发，航段最长 4096 格。拆盒需要安全、可放置、可打开及可回收的操作位置；正在进行的盒子事务完成后再核验数量。盒子、任务货物及其他预留物品保留原有保护。

例如离开传送门的短跳飞最低需要 4 发，L0 现存 166 发，就可以先离开门口，再在后续需要拆盒时寻找安全位置。

散装检查负责这段飞行的可用性。高层固定水位负责补给频率；实际消耗由飞行控制状态决定。

## 消耗、预算与边界

控制器加速请求的冷却为 36 tick。`FireworkUseFlow` 核验推进燃料、消费权限及实际减少数量，再结算 1 发。带爆炸效果的烟花继续排除。

飞行失败时，恢复流程寻找可观察、可安全到达的本地落点。任务需要返回时，单独声明返回目的地与旅行。未加载目标的本地导航预检保留鞘翅耐久检查；施工补给采用当前水位策略。一次执行的运输准备与材料获取共享维护预算及上次成功来源。

预测使用坐标和传送记录；绕障、起降调整及出口变化会产生偏差。默认固定水位适合储备充足、距离受控的任务。极长距离仍需要结合实际路线和可达来源判断。

维护次数、活动时间和父流程余量见[预算](./budgets#补给预算与时间余量)。库存诊断见[库存要求与水位](../supply/stock#查询库存)。
