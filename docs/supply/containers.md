# 容器取货与潜影盒

容器取货将来源任务中的数量转为 Bot 实际取得的物品。流程核对现场内容、物品筛选条件和背包容量，并保留每次转移及借盒的责任。

## 库存与容器术语

| 术语 | 具体含义 |
| --- | --- |
| 来源容器 | 当前取货任务访问的实际库存，如箱子或已放置潜影盒 |
| 散装物品 | 玩家背包或容器槽位中可直接转移的物品堆 |
| 盒内物品 | 作为物品携带的潜影盒内部库存，使用前需要访问或拆取 |
| 临时放置位 | 满足放置、打开、挖回及拾取条件的潜影盒作业位置 |
| 来源借盒 | 从来源暂时取走的带货盒，拆取后必须归还余料连盒 |
| 运输盒 | Bot 用于携带及整理本次物资的盒子 |
| 空盒材料 | 需求中的潜影盒物品，要求盒内没有其他物品 |
| 取货回执 | 实际确认取得的数量、转移记录和未结责任 |

来源借盒、运输盒和空盒材料具有不同用途。盒内的数量可以参与库存观察；能够立即转移或使用的数量还取决于拆盒和容量条件。

## Atlas 来源状态

Atlas 保存容器位置、物品数量、盒内内容和访问评估。`ADMISSIBLE` 表示已观察的容器符合取货策略，实际访问时仍核对现场；`PROTECTED` 表示有明确保护原因；`UNKNOWN` 表示评估所需的证据不完整。

跨区块邻居尚未加载时，容器可以保留完整的物品记录，同时标记为 `UNKNOWN`。查询可取库存与统计世界总库存因此会得到不同数量。规划缺料时，通用勘察流程可前往候选来源，补充现场观察并重新规划；来源数量与路线可达性分别判断。

普通烟花的数量还需经过组件筛选：含爆炸效果的烟花不进入飞行燃料库存。盒装库存通过潜影盒内容参与数量统计，取用时复用下面的容器和拆盒流程。

## AcquireContainerItemsFlow

**输入：**容器位置、物品数量表、执行模式、物品筛选规则，以及可选容量恢复操作。

```text
准备背包容量
  → AccessContainerFlow：到达并打开来源
  → 转移符合条件的散装物品
  → 需要盒内物品时，借盒并精确拆取
  → 核对实际取得量、剩余需求与借盒责任
```

一次转移受实际源库存和可用容量限制。来源耗尽、容量不足或访问失败时，回执保留已经确认的转移；上层据此决定换源、恢复容量或结束。

**完成结果：**`AcquisitionReceipt`，包含取得量和借盒归还状态。上层根据实际数量继续结算需求。

## BorrowSourceShulkerFlow

**输入：**原来源容器、盒子所在槽位、盒子及元数据、要拆取的数量和执行模式。

以需求 10 个物品、盒内有 64 个为例：

1. 核对来源与原盒，记录借用关系。
2. 取出原盒，寻找安全作业位置。
3. 放置、打开盒子，实际取出 10 个。
4. 关盒、挖回，并核对盒子已进入背包。
5. 返回来源，核对容器及槽位身份，把剩余 54 个连盒放回原槽位。

原槽位、盒子元数据和剩余内容在归还时校验。即使材料已取到，盒子丢失、容器被替换或归还失败仍留下未结借盒责任，需要恢复或明确报告。

无损调试模式使用受记录的副本，取得物品后回收该副本，保留原来源库存。模式说明见[交付与结果](./delivery#执行模式)。

## AccessShulkerStagingFlow

这个组件选择并到达通用潜影盒作业位置，可供运输盒拆取、打包和资源补给复用。

候选位置检查承重、盒子开启空间、实体占位、人物站位、操作距离，以及挖回后的拾取安全。实体碰撞检查与原版放置要求一致，动物占用的格子会被排除。到达后重新核对现场；放盒前若位置已被占用或地形改变，使用同一搜索重新选择，最多调整3次，仍受该次作业的总超时限制。

前往作业位置复用局部导航，可以步行或使用鞘翅。该段飞行由 L0 已备好的散装烟花供能；到达作业位置前，盒内物资保持封存。若当前燃料不足，返回明确的缺料结果，避免为了打开燃料盒而再次请求打开燃料盒。

寻找作业位置可能使 Bot 离开原路径或施工面。拆取与回收完成后，父执行依据 Bot 的实际位置继续原目标；旅行重新选路，施工先重新到达所需操作站位。

选择作业位置与实际打开、拆取、回收由相应组件协作完成。盒子及其内容始终由发起该次操作的流程持有责任。

## 容量与分批

普通取货按 L1 的接收容量分批执行。每批转移或借盒归还后，先通过 `EnsureInventoryReadyFlow` 整理，再继续取货或旅行；自有运输盒提供 L2 容量。借盒使用 L0 工作槽，获取空运输盒的启动过程可以利用剩余物理空位。

`incoming` 的总量用于估算随身运输容量，下一批的散装接收空间单独检查。大批物品通过多次接收、装盒完成。容量准备也可以拆出已有盒内的下一批材料，或调用上层提供的外置库存周转操作。

交付型供给在支持的路径中可先交付已取得的散装货物，再返回继续。获取型流程与施工子流程按各自接入方式组织容量；[施工物资与补给](../construction/supplies)说明当前边界。

普通挖掘掉落物的尽力回收策略单独配置。潜影盒及借盒归还保留专门保护，参见[清场回收](../construction/clearing#产物回收)。
