# 清场与建造

## 区域清理

`ExcavateAreaFlow` 清理当前维度的包含端点区域：每轴最多 64 格，总体积最多 32768 格。Bot 使用生存模式，并准备工具、有限空潜影盒及填料。区外仓储点互不重复，每处放置运输盒保存掉落物。

```text
/ltv Worker exec ExcavateAreaFlow 100 64 100 104 66 104 98 64 100
```

流程从上往下挖掘，核对拾取，容量不足时入库，最终核验区域为空且液体稳定。机器、容器、传送门等保护冲突会报告坐标。

## 液体与出口

内部液体用有限填料处理，临时填料最终回收。外部持续来水通过 `--seal` 指定区外封堵点，永久挡水块分别记账并保留。

浅坑水柱出口适用于已清空、最大深度 4 格、水平 8×8、底部与四周封闭且水可存在的区域。Bot 使用水桶放水、游出、收水，再核验连续 100 tick 为空。其他出口由导航和飞行能力处理。

## 恢复清场

```text
/ltv Worker exec ResumeExcavation {"taskId":"00000000-0000-0000-0000-000000000001"}
```

使用清场 trace 中的业务 `taskId`。检查点在世界 `lattivium/excavations/`，恢复核对身份、库存、回执及剩余义务。

## 原理图建造

```text
/ltv Worker exec BuildSchematicFlow small.litematic 100 65 100
```

流程读取受支持的有限原理图、补料、旅行、勘察、逐块施工并核验最终状态。当前保留现场本来正确的方块；层序清场、通行空间和复杂施工扩展按具体能力逐步推进。文件位于世界 `lattivium-atlas/schematics/`，原点属于 Bot 提交任务时的维度。
