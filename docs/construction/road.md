# 连接道路

连接道路将井口接入工作站，同时为工作站第一块地板提供施工起点。建成后作为永久设施保留。

## 通行截面

![道路截面与逐块放置前沿](/construction/road-section-zh.svg)

一格宽的路线包含三层空间：底层为路面，上方两格为人物净空。道路规划检查整个截面，并验证下一块路面能从已建部分实际放置。

工作站高于原井口时，计划包含所需的垂直脚手架连接及材料用量。

## 逐块施工

从井侧可靠支撑出发，沿规划顺序延伸路面。每次放置后核对方块状态与实际材料消耗，再移动到下一处施工姿态。

道路末端直接接入工作站地板，随后从该位置展开平台。永久道路承担后续往返用途。

脚手架顶部接路可能需要一块临时实体支撑。它用于建立侧面的道路起点；侧路可站立后，回收临时块并恢复井口净空。完成时核验恢复后的实际上下通行。

## 完成条件

路面连续，人物净空畅通，两端分别接入井道和工作站。Bot 实际完成双向通行，放置范围及材料收据与计划一致。

## 实现组件

`BuildBlockFlow`、`PreparePlatformFlow` 与 `ApproachPlatformPlacementFlow` 提供放置和边缘施工能力。

`PrepareSiteRoadFlow` 接收 `SiteInfrastructurePlan`，负责井顶延伸、临时支撑、永久路面、临时块回收和往返核验；场地准备流程调用它来连接井道与工作站。
