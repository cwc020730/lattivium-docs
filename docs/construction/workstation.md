# 工作站

工作站为施工提供地板、物资存储和整理空间。它可以建立在空中，通过永久道路连接井口。

## 布局

`WorkstationLayout` 使用输出容器数量决定占地：

| 项目 | 布局 |
| --- | --- |
| 输出潜影盒 | 2～8 个，间隔排列 |
| 物资箱 | 1 个位置 |
| 空盒箱 | 1 个位置 |
| 地板 | 宽度为输出盒数量 × 2 + 1，另一边为 7 格 |
| 净空 | 地板上方 2～6 格，由布局指定 |

例如，4 个输出盒对应 9×7 地板，共 63 格。通道和容器开启空间包含在布局中。

## 空中平台

联合设施方案先找到完整空体积，再从永久道路末端铺地板。采用统一的白名单地板材料，优先白色混凝土。

站位搜索与道路规划共同决定施工高度。地板及人物净空必须位于世界高度范围内。

每次放块先准备可直接使用的建材，再前往施工站位。建材装在随身运输盒中时，Bot 使用通用库存周转寻找可操作位置拆取，并在前往施工点期间保留当前所需数量。高处站位可使用已具备条件的步行、攀爬或鞘翅路线。

## 物资与完成检查

铺好地板后放置输出盒和存储箱，按任务要求存入物品。完成时核对：

- 实际地板与计划一致。
- 通道及容器上方空间畅通。
- 容器类型、位置及实际库存符合收据。
- 井道至工作站可以实际往返。

## 实现组件

`PrepareWorkstationFlow` 管理平台准备、容器放置、物资存入及核验，复用 `PreparePlatformFlow` 建立地板。

组件支持指定区域的清理与换地板。联合设施方案为它提供已选好的空中布局，并从连接道路末端展开平台。连续清场还使用工作站的产物仓储位置，以及海绵模式下的熔炉作业位置。
