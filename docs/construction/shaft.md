# 井道

井道提供地面与施工层之间的垂直通行。贴边的脚手架列可以在不同高度连接相邻施工层；该层侧面净空和落脚支撑就绪后，Bot 即可从柱上进入。脚手架根部可以低于最底施工层。

![脚手架根部、施工层与井口的相对位置](/construction/shaft-section-zh.svg)

## 位置与通行

| 名称 | 意义 |
| --- | --- |
| 根部 | 承托脚手架的可靠方块位置 |
| 井口 | 接入地面或连接道路的顶部入口 |
| 施工层连接 | 脚手架与当前施工层相邻的通行位置，随施工高度变化 |
| 井底侧向作业位 | 需要从侧面搭脚手架时使用的站位，按施工方案单独规划 |

根部向下延伸时，各施工层的高度保持不变。井底侧向作业位服务于搭架等操作；井旁必要施工站位属于计划中的修改范围。

## 施工顺序

1. 核验根部、井柱、必要站位及周围安全条件。
2. 使用安全的逐步下降和原生挖掘动作建立通道。
3. 从可放置姿态安装脚手架。
4. 实际完成上行、下行和出口通行检查。

开工物资及存储空间需要支持这一阶段，因为工作站在井道之后建立。

## 完成条件

脚手架列具有可靠支撑，出入口净空满足人物通行；各施工层所需支撑与底部开口相容。世界中的方块状态和实际往返结果共同决定井道是否完成。

## 实现组件

`ScaffoldAccessPlan` 表达脚手架通道布局。`PrepareScaffoldAccessFlow` 已提供井内受控挖掘、掉落物收取、脚手架放置和通行验证。

四边沙墙方案使用 `PrepareSealedScaffoldFlow`：先在选定井心内外建立隔水沙柱，再挖去井心沙子并安装脚手架。隔水列和脚手架从计划底部延伸到墙顶。

干地场地计划记录选定井位、根部与出口高度，以及必要的井口延伸。内部 Flow 的参数由调用方提供；可独立执行的命令由[执行契约](../reference/executables)定义。
