# Coverage and version

This manual covers declared execution entries, positional syntax, execution control, configuration, input formats, debug HTTP and public Java APIs. Task, Flow and Action have separate references.

This manual describes the current development version. Use `/ltv schema` and `/ltv schema <entry>` on the server to inspect its runtime entries and parameter contracts.

`execution-catalog.json` is exported from runtime contracts. `reference-manifest.json` records the entry list and source file hashes. Build checks validate entry coverage, bilingual pages and contract consistency.
